\section{方案 B · 宇树 S288 升级版 —— \bad{已否决，勿重踩}}
\noindent\bad{\textbf{否决结论}：价格倒挂 + 改动全盘化 + 收益存疑，三票否决。保留本节作决策记录。}

\subsection{否决理由}
\begin{enumerate}[nosep,leftmargin=1.5em]
\item \textbf{价格倒挂}：S288 标准版实价 ¥199$\times$15 = ¥2,985，比 XL330（代理店 ¥95--238）\bad{还贵}。
"国产替代"反而更贵，5 台单台 ¥4,300--5,200 已超官方整机售价 \$399$\approx$¥2,850——卖不动。
（¥99 学生价需客服申请且入口禁用，即使拿到也只是把"贵"变回"一样贵"。）
\item \textbf{改动是全盘的}：换电机 $=$ 换一台机器人。
电压（2S$\to$3S，供电树重画）、总线（Dynamixel V2 $\to$ 宇树 6Mbps 私有 1-Wire，rustypot 不支持需自写驱动）、
IMU 被踢出总线（S288 仅 15 地址，15 舵机占满 $\to$ IMU 改 I2C 直连）、
BAM 执行器模型全部重标、\textbf{9 个官方 ONNX 全部重训}、机械件舵机腔重挖。
研发成本比省下的钱高一个量级。
\item \textbf{收益存疑}：FOC 阻抗 + 输出端编码器确实先进，但对 737g 小鸭子，
官方 kp=200 位置环已够用（官方自己仍在该架构上出货）。性能提升没有对应的应用买单。
\end{enumerate}
\noindent\textbf{若未来重启此线的唯一条件}：拿到宇树教育批量价（$\le$¥99/个，即 200 台档）
且宇树愿意提供驱动层技术支持——两条同时成立才值得再评估。

\subsection{原分析存档（数据仍有效）}
S288 标准版 ¥199/个，19.5g、288.35:1 同减速比、M2 安装、单线 TTL。
FOC 阻抗控制（$\tau_{ff}+k_p\Delta p+k_d\Delta\omega$）；输出端 13-bit 编码器消灭回差。
单台 BOM（按 ¥199）：S288 ¥2,985 + Radxa ¥150--300 + IMU ¥20 + 摄像头 ¥30 + ToF ¥78 +
3S 电池 ¥60 + 打印 ¥35--60 + 紧固 ¥40--60 + 手柄 ¥100--150 $= \textbf{¥4,300--5,200}$。

\section{方案 C · Open Duck Mini v2（全开源硬件，最快整机）}

官方 BOM/CAD/装配/接线全套公开 + 中文社区教程（zihao 飞书 / Tnkr 指南）。
STS3215 $\times$16（¥50--99 实价 $\to$ ¥800--1,584）+ Pi Zero 2W（¥128--148）+ BNO055 + MAX98357A +
脚底开关 + 18650$\times$2。\textbf{零打板、全模块}。官方 BEST\_WALK ONNX 可跑；重训走 Open\_Duck\_Playground。
单台 \textbf{¥1,700--2,100}；5 台 $\approx$¥8,500--10,500；200 台 $\approx$¥34--42 万。
代价：它是 42cm/2.1kg 的"大鸭"，无摄像头/ToF。

\section{方案 D · 极简原尺寸版}

保持 25cm 外观，舵机腔按 STS3215 重挖（FreeCAD 仓装配体为起点），结构件加厚；
STS3215$\times$15 + 香橙派/Pi Zero 2W + 飞特驱动板（rustypot.feetech 官方支持）+ LSM6DSV16X I2C 模块 +
5V BEC + 2S 电池。策略全重训（执行器参数差一个量级：kp 17.8 vs 0.55，Open Duck Mini 的
STS3215 标定可直接抄）。单台 \textbf{¥2,100--2,700}；5 台 $\approx$¥10,500--13,500；200 台 $\approx$¥42--54 万。
\warn{务必先仿真验重量预算再下单}——同架构换 STS3215 整机质量 $\times$2.86（社区实测 2107g）。

\section{装机与验证路线（摘要）}
