## 二、IMU 缺口全景（imu_to_dxl 板 = A 方案唯一必做自制硬件）

### 已有（不用再做）

| 项 | 内容 | 来源 |
|---|---|---|
| 协议契约 | Dynamixel V2 从机；ID 200；reg 124 起 12 字节（gyro i16 ±500dps 17.5mdps/LSB + SFLP 四元数 fp16 xyz，w 主控自算）；诊断块 20 字节 | 官方 Rust 源码逆向（`00_wiki/03`） |
| 器件选型 | LSM6DSV16X + STM32G030/CH32V203 + 半双工收发 + 总线取电（注意总线 VDD=电池 7.4V，LDO 耐压 ≥10V） | `03_pcb/imu_to_dxl_规格书.md` |
| PCB 工艺参数 | 2 层 / ≤20×15mm / 1.0mm / 嘉立创经济款 / M2×2 孔位 | 同上 |
| 验证流程 | PING ID200 → READ 124 → 静置/翻转数据检查 → 挂真总线 50Hz 稳定 → 与评估板对比 <2° | 同上 |

### 缺口清单（按依赖顺序）

| # | 缺口 | 说明 | 工作量 | 依赖 |
|---|---|---|---|---|
| G1 | **原理图+PCB（KiCad/立创EDA）** | 按规格书画：LSM6DSV16X(SPI) + MCU + 74HC125 自动方向 + LDO + 2×JST-PH3 | 2-3 天 | 无 |
| G2 | **MCU 固件：Dynamixel V2 从机栈** | 1Mbps UART DMA 收发、CRC16、PING/READ/SYNC_READ 应答、ID/波特率 EEPROM 区 | 3-5 天 | G1 选型 |
| G3 | **固件：LSM6DSV16X 驱动 + SFLP** | SPI 8MHz 读 ODR≥200Hz；开 SFLP game rotation + gyro FIFO；fp32→fp16 打包 | 2-3 天 | G2 |
| G4 | **调试器/工具** | USB 转 TTL（或 U2D2）+ rustypot/铁心工具扫描；逻辑分析仪抓总线时序（1Mbps 半双工方向切换是调试重点） | 0.5 天采购 | G1 |
| G5 | **台架联调** | 单板 PING → 数据合理性 → 挂 15 舵机总线 → 官方 robotd 读取 | 2-4 天（含 1-2 版返工） | G1-G3 |
| G6 | **双板冗余** | 首版打 5 片，预留 2 片返工 | 已在打样费内 | G1 |

**关键风险**（从规格书提炼，动手前必读）：
1. **半双工方向时序**——TX 使能由数据沿 RC 触发；官方无方向 GPIO，纯硬件自动方向。
   建议首版留一个手动方向 GPIO 跳线（调试用），量产去掉。
2. **总线取电 vs 外部供电**——首版建议留外部 5V 供电焊盘（避免调试时被舵机总线噪声干扰），
   验证后再切总线取电。
3. **1Mbps 下 MCU 余量**——STM32G030 @64MHz 够用，但 CRC16 查表法别用逐位；
   CH32V203 更便宜但 USB 烧录生态弱一档。

### HAT 板缺口（可全部绕开）

| 官方功能 | 复刻替代 | 需要做吗 |
|---|---|---|
| TLV320AIC3104 音频 codec | 不要 mic/喇叭 → 直接省略；要音频 → USB 麦 + MAX98357A 模块（¥10） | 否 |
| 供电过板（电池→主控） | USB-C 5V 直供 or NP-F 座线直出 | 否（一根线的事） |
| Stemma ToF 口 | VL53L8CX 模块 4 线直插 pin3/5（I2C3） | 否 |
| BMI088（官方休眠件） | 忽略 | 否 |
| **半双工自动方向电路** | **唯一必须保留的 HAT 功能** → 并入 imu_to_dxl 板或独立小转接板 | 是（并入 G1） |
