\section{方案 B · 宇树 S288 升级版（量产优先，推荐）}
\subsection{为什么 S288 是量产最优解}
\begin{itemize}\itemsep0pt
\item \textbf{¥99/颗}（宇树官方旗舰店实价）= XL330 的 42\%，力矩反升 1.5Nm vs 0.96Nm
\item 19.5g vs 18g；同为 288.35:1 减速比、M2 螺丝、单线半双工 TTL——机械改动极小
\item \textbf{输出端 13bit 编码器}：直接消灭回差问题（官方为 XL330 建了整套
  \texttt{passive\_*\_backlash} 模型，S288 不需要）
\item 阻抗控制（$\tau_{ff} + k_p\Delta p + k_d\Delta\omega$，FOC 底层）：
  \texttt{limp\_fall} 不再靠降增益硬扛
\end{itemize}
\subsection{必须解决的三面墙}
\begin{enumerate}\itemsep0pt
\item \textbf{电压}：S288 为 3S 12.6V（XL330 为 2S 7.4V）→ 换 3S 电池组，BEV 降压轨重设计
\item \textbf{总线容量}：S288 总线仅 15 地址（0--14）→ 15 舵机占满，IMU 改走主控 I2C 直连
  （LSM6DSV16X 模块 ¥20）
\item \textbf{驱动层}：rustypot 无 S288 支持 → 按宇树手册自写从机驱动（6Mbps 1-Wire）
\end{enumerate}
\subsection{策略}
BAM 标定重做（S288 无转子侧回差，模型反而更简化）→ microduck\_rl 重训全部技能。
10 页训练步骤见 wiki 第 10 页；本机 gait-v1 已验证全链路（0 摔/20ep）。

\section{5 台起步 → 200 台放量的路径}

\begin{enumerate}\itemsep2pt
\item \textbf{第 1--2 周}：方案 C 或 D 打样 1 台（机械验证 + 步态复现）
\item \textbf{第 3--4 周}：按选定方案 A/B 买 2 颗电机台架标定（BAM 参数），
  microduck\_rl 重训，\texttt{-Backlash-} 变体验证鲁棒性
\item \textbf{第 5--8 周}：5 台试产——imu\_to\_dxl 打样 5 片、结构件批量打印、
  逐台 50Hz sync\_read 点检
\item \textbf{第 3--6 月}：200 台放量——电机批量议价（S288 预估 ¥93--95），
  结构件改注塑或 resin 批量，PCB 转 SMT 贴片批量
\end{enumerate}

\subsection{放量的成本杠杆}
\begin{itemize}\itemsep0pt
\item 电机批量议价：S288 200 台档预估 ¥93--95（官方旗舰店对公）
\item 3D 打印转小批量注塑：47 件结构件单台从 ¥180 降至 ¥65（开模费摊销另计）
\item PCB 打样转批量 SMT：单片从 ¥40 摊至 ¥18
\item 风险：XL330 供货与价格波动（欧洲 €45.76/颗 vs 国内 ¥120，仍有 3 倍空间，
  但渠道以贸易商为主，直采需 ROBOTIS 授权经销商）
\end{itemize}
