# 06 · 装机步骤核查表（step-by-step）

> 适用于方案 A（忠实复刻）；C 方案用 Open_Duck_Mini 官方 assembly_guide。
> 每完成一项打勾并记录日期。⚠️ = 有实测数据支撑的注意点。

## 阶段 0 · 环境与资料（✅ 本库已完成）

- [x] 官方仓 10 个克隆归档（01_official + 02_cad）
- [x] 9 个策略 ONNX + manifest + SHA256
- [x] E1 本机仿真跑通官方行走策略（`--new-cmd-obs` 必须）
- [x] E2 浏览器沙盒验证（FPS 60 / CTRL 50HZ）
- [x] E5 STL 网格体检：熔合后 47/47 水密
- [ ] E4 aarch64 交叉编译（进行中）
- [ ] E3 本地训练闭环（进行中）

## 阶段 1 · 采购到货核验

- [ ] XL330-M288-T ×15 —— 核对 M288（不是 M077 高速版）；通电前统一刷 ID/波特率
      （右腿10-14/左腿20-24/颈头30-34，baud_rate=3 → 1Mbps，协议 V2）
- [ ] Radxa Zero 3W（1GB/32GB eMMC 带排针 SKU）
- [ ] NP-F550 ×1 + 座 ×1；IMX219 摄像头；VL53L8CX 模块
- [ ] LSM6DSV16X 模块或自制 imu_to_dxl 板（见 08-打板指南）
- [ ] M2 螺丝套装（4/6/8/12 = 60/80/40/15 + 螺母50 + 热熔60）+ 轴承 22×16×4×2、15×10×3×3
- [ ] 蓝牙手柄（标准 HID）

## 阶段 2 · 打印

- [ ] STL 单位转换：**上游是米**，切片前 ×1000（或切片器缩放 1000%）
- [ ] 逐件切片（先小件试装配验证公差）：⚠️ FDM 孔径会偏小 0.1–0.3mm，
      Ø2.2 过孔先打试件，必要时钻头扩孔
- [ ] 腿部结构件（leg/hip/yaw2roll）×2 套 → M2 试装（社区已实物验证 M2 孔位可用）
- [ ] 躯干/头壳/颈 → 多色按需
- [ ] TPU 柔性件（jaw_soft 等 4 件）
- [ ] 记录：打印机/层高/填充/耗时/失败件 → 填 `07_build_log/`

## 阶段 3 · 电控制作

- [ ] imu_to_dxl 板打样贴片（或模块直连替代——软件需改 IMU 读取路径）
- [ ] 固件：Dynamixel V2 从机 @ID200 reg124，12 字节布局见 03 页
- [ ] 台架测试：usb2dynamixel/USB 转 TTL + robofriend 工具逐 ID 读写
- [ ] HAT 简化方案：5V USB-C 供电板 + Stemma ToF 直插 pin3/5（放弃音频则免 codec）
- [ ] 半双工方向电路：无方向 GPIO，靠硬件自动方向（74HC126/专用收发）

## 阶段 4 · 主控系统

- [ ] Armbian 写入 eMMC（maskrom 或官方镜像）
- [ ] `systemctl mask serial-getty@ttyS2` ⚠️ 坑1
- [ ] i2c3 M0 overlay + 禁 fusb302 ⚠️ 坑2；udev 规则 `/dev/i2c-pihat`
- [ ] NPU overlay（如需 rknn）⚠️ 坑3
- [ ] 官方 Rust 运行时部署（同款主控直接用；构建见 04 页 E4）
- [ ] 9 个 ONNX 放入策略目录，`robotctl policy load` 逐个验证 obs[1,61]/act[1,14]

## 阶段 5 · 总装

- [ ] 腿部：hip_yaw→roll→pitch→knee→ankle 链，轴承压入，螺丝点乐泰（金属位）
- [ ] 躯干：电池座 + 主控 + HAT/供电板 + 走线（颈部动态弯折区留余量）
- [ ] 颈/头：4 DoF + 嘴连杆（第 15 舵机 ID34）
- [ ] 摄像头倒装 180°（rotation=180）；ToF 装 Stemma 口
- [ ] 称重（目标 ~737g）+ 重心（躯干前移 ~5mm 对齐踝轴——STAND2 姿态即为此设计）

## 阶段 6 · 点检与首跑

- [ ] 上电前：万用表量电源轨；所有舵机 ID 扫描（16 设备全应答）
- [ ] 空载：50Hz sync_read 稳定性 ≥ 官方水平（丢包 ~0.27%/分钟属正常）
- [ ] 电压 EMA 行为：6.6V 阈值自动坐下关机
- [ ] 手柄配对 → 低增益站立 → alpha_walking 上机
- [ ] limp_fall 测试：推倒 → 增益 200→50 软着陆 → 600ms 回站姿
- [ ] 逐技能验证：walk/sit/stand/kick/ground_pick/roller/roulade
- [ ] 问题记录进 `07_build_log/`
