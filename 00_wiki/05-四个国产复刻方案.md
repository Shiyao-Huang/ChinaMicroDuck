## 方案 A · 忠实复刻（推荐给"保真优先"）

**机械**：`02_cad/upstream_stl/` 47 件（E5 已验证水密，切片前 ×1000 转 mm）+
`02_cad/replica_assembly/microduck-replica/cad/` 15 部件装配体直接进 CAD。
M2 螺丝系统（Ø2.2 过孔×77 / Ø4.4 沉头×28 / Ø1.6 底孔×20），采购量见紧固件反推表。
轴承 22×16×4 ×2 + 15×10×3 ×3。PLA/PETG，TPU 用于 jaw_soft 等柔性件（FreeCAD 仓标 4 件）。

**电控**：
- Radxa Zero 3W（选 1GB RAM + 32GB eMMC SKU，对应官方 1GB/32GB 规格）
- 自画 `imu_to_dxl` v2：LSM6DSV16X + STM32G030/CH32V203 + 半双工 TTL 收发，协议已完整逆向
  （ID 200、reg 124、12 字节 gyro i16±500dps/17.5mdps·LSB + SFLP 四元数 fp16）→ 规格书见 [08-打板指南](08-打板指南.md)
- HAT 板可简化：不要录音/喇叭可完全省略；ToF 用 Stemma 现成模块直插 pin3/5
- 摄像头 IMX219（Pi Cam v2）倒装 180°；电池 NP-F550 + 卡座

**软件/策略**：官方 Rust 运行时原样跑（同款主控 = Apache-2.0 直接用）；9 个官方 ONNX 零训练即用（E1 已验证本机推理契约）。

**装机要点**：mask serial-getty@ttyS2；i2c3 用 M0 pinmux 禁 fusb302；NPU 要刷 overlay。

**验证状态**：仿真/推理/网格已实测；PCB 待画；整机待装。

## 方案 B · 宇树 S288 升级版 —— ❌ 已否决（2026-09-02）

**否决三票**：
1. **价格倒挂**：S288 标准版实价 ¥199（天猫官方旗舰店有货）×15 = **¥2,985，比 XL330（¥95-238）还贵**。
   单台 ¥4,300-5,200 已超官方整机 ¥2,850——"国产替代"反而更贵，卖不动。
   （¥99 学生价入口当前禁用 + 需客服申请，即使拿到也只是"一样贵"。）
2. **电机一改，全盘都改**：电压 2S→3S 供电树重画；总线协议 Dynamixel V2 → 宇树 6Mbps 私有
   1-Wire（rustypot 不支持，自写驱动）；IMU 被踢出总线（S288 仅 15 地址）改 I2C 直连；
   BAM 执行器模型重标；**9 个官方 ONNX 全部重训**；机械舵机腔重挖。研发成本 >> 省下的钱。
3. **收益存疑**：FOC 阻抗 + 输出端编码器虽先进，但 737g 小鸭用官方 kp=200 位置环已够用
   （官方自己仍在此架构上出货）。性能提升没有买单方。

**重启条件（两条同时成立才再评估）**：宇树教育批量价 ≤¥99/个（200 台档）+ 宇树提供驱动层技术支持。

**官方询价通道**（已核实）：unitree.com/cn/booking「采购/合作」表单 · 400-626-6518 ·
sales_global@unitree.com。学生话术模板见 `07_build_log/询价沟通记录.md`。

## 方案 C · Open Duck Mini v2 血统版（推荐给"最快跑起来"）

Microduck 的亲前身（同一工程师 Antoine Pirrone），**硬件完全开源**——这是唯一有
官方 BOM + 可编辑 CAD（Onshape 公开文档）+ 装配/打印/接线全套文档 + **中文社区教程**的路线。

- 机械：Onshape CAD（可导出 STEP/STL）+ `02_cad/openduckmini/Open_Duck_Mini/print/` 全部 STL +
  print_guide（PLA 15% 填充 + TPU 脚垫）+ assembly_guide（M3 热熔螺母 + 乐泰 243）
- 舵机：STS3215 ×16，¥60–70/颗，深圳飞特现货
- 电控：**零打板**——Pi Zero 2W + Waveshare 舵机驱动板 + BNO055 IMU 模块 + MAX98357A 音频 + 脚底开关
- 策略：仓内 `BEST_WALK_ONNX.onnx` 可直接跑；重训走 Open_Duck_Playground（MuJoCo Playground/MJX）
- 教程：Tnkr 指南（tnkr.ai）+ zihao 飞书中文 wiki（BOM 中文版 + 搭建教程，链接见 07 BOM 页）
- 代价：它是 42cm/2.1kg 的"大鸭"，不是 25cm 那只；无摄像头/ToF/NFC（表达功能后补）

**BOM 官方表**：Google Sheets（README 链接），目标 <$400。

## 方案 D · 极简原尺寸版（推荐给"预算紧但要 25cm"）

保持 Microduck 25cm 外观与装配关系，电控全面模块化、零打板：

- 机械：同方案 A 的 STL，但舵机腔按 STS3215 尺寸重挖（FreeCAD 仓的多零件装配体是现成起点）；
  STS3215 比 XL330 大一档 + 重 3 倍 → 结构件需加厚加强，整机预计 ~800–900g
- 舵机：STS3215 ×15（力矩 1.86 N·m 反而富余）
- 电控：Pi Zero 2W / 香橙派 Zero3 + 飞特串口舵机驱动板（1Mbps，`rustypot.feetech` 官方支持）+
  LSM6DSV16X I2C 模块 + 5V/6V BEC（STS3215 供电）+ 2S 电池
- 策略：**全部重训**（执行器参数差一个数量级：kp 17.8 vs 0.55、armature 15.5×——
  Open_Duck_Mini 的 STS3215 标定参数可直接抄，血统相同）；训练用 Apple lab 原型 + GB10 正式训
- 已知教训：社区实测同架构换 STS3215 → 整机 2.86 倍质量；缩在 25cm 里是激进路线，
  **务必先在仿真里验重量预算再下单打印**
