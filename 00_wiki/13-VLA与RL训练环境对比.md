# 13 · VLA 训练 vs RL 训练 —— 环境差异大到什么程度

> 一句话：**差异是本质性的——两者连"数据从哪来"都相反**。
> VLA 吃的是人类演示数据（不需要仿真器），RL 吃的是仿真器自我生成的经验（不需要人类数据）。
> 但它们不是二选一：真机产品最终架构 = VLA 大脑(1-2Hz 决策) + RL 小脑(50Hz 执行)。

## 硬对照表

| 维度 | VLA (OpenVLA / π0 / RT-2) | RL (microduck_rl / 本方案) |
|---|---|---|
| **数据来源** | 人类遥操作演示：真人拿手柄控真鸭，摄像头+舵机角同时录 | **零人类数据**——MuJoCo 里每步自生成 |
| **学习范式** | 监督学习（模仿）+ 视觉-语言预训练 | 试错 + 奖励信号（无标签）|
| **仿真器** | **不需要**（训练在真实数据上） | **必需**（MuJoCo 是唯一的"世界"）|
| **视觉输入** | **必须**——摄像头图像是核心输入 | **没有**——61 维本体感知（IMU+关节角）|
| **语言输入** | 必须（指令如 "pick up the cup"）| 无 |
| **输出形式** | 离散动作 token（~2-10Hz 一段轨迹）| 连续向量（50Hz 逐指令）|
| **算力形态** | GPU 集群训 + 单卡推理（7B 级）| 32 envs CPU 可训 / 4090 上 4096 envs|
| **失败模式** | 数据分布外场景不会做 | reward hacking / 姿态 hack |
| **本仓库状态** | 未开始（无真鸭、无遥操作设备）| **已闭环**（v5-v7 全流程验证）|

## 环境需求差异的根源

**VLA 为什么不需要仿真器**：它的能力来自"看过人怎么做"。10 万条人类演示视频就是教材。
仿真器只是数据增强工具（可选）。

**RL 为什么不需要人类数据**：它的能力来自"试出来的"。奖励函数定义了"什么是好"，
仿真器提供"试"的场所。人类数据反而会把策略锁死在人类水平。

## 真机产品的最终架构（两者各就各位）

```
┌──────────────────────────────────────────────┐
│  VLA 大脑 (1-2 Hz)                            │
│  输入: 摄像头图像 + 语言指令                    │
│  输出: 高层意图 ("走到球前踢一脚")              │
│  = 场景理解 + 任务规划 + 异常判断               │
├──────────────────────────────────────────────┤
│  RL 小脑 (50 Hz) ← 我们已经训好的              │
│  输入: 61 维本体感知 + 大脑下发的命令槽          │
│  输出: 14 舵机目标                             │
│  = 平衡 + 步态 + 卡点 + 摔倒恢复               │
└──────────────────────────────────────────────┘
```

我们已有的 v6b/v7 卡点策略 = 完美的"小脑"。VLA 要补的是"大脑"——它需要：
1. 一只**真鸭**（或高保真仿真 + 遥操作接口）
2. **遥操作设备**（手柄就够——官方 padd 就是）
3. **GPU 集群**训 7B 模型（4090 单卡只能推理）

## 4090 在两条路线中的角色

| 路线 | 4090 能干什么 |
|---|---|
| RL（当前主线）| 官方 mjlab 4096 envs 并行 → 训练提速 ~100× |
| VLA（未来）| 推理：OpenVLA int4 单卡可跑；训练 7B 要多卡 |
