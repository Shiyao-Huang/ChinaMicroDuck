## imu_to_dxl v2（唯一必须自画的板）

| 项 | 值 |
|---|---|
| 功能 | 把 IMU 做成 Dynamixel 从机，与 15 舵机同一次 sync_read 读出 |
| 寄存器 | 地址 124，控制环读 12 字节（诊断块 20 字节） |
| 字节 0..6 | gyro x/y/z，i16 小端，±500 dps，17.5 mdps/LSB |
| 字节 6..12 | SFLP 四元数 x/y/z，fp16；w=√(1−x²−y²−z²) |
| BOM | LSM6DSV16X + 小 MCU（STM32G0/G4、CH32V203、ESP32 均可）+ 半双工 TTL 收发 + 总线取电 |

## 软件对齐参数（换硬件必须保持）

| 参数 | 值 |
|---|---|
| 控制环 | 50 Hz（继承自树莓派原型） |
| 策略 | obs[1,61] → act[1,14]（61=48 本体感知 + twist3 + head4 + body6） |
| action_scale | 0.9（走）/ 0.8（轮滑） |
| 位置 P 增益 | 200（站立 ×0.8，limp_fall 摔倒时降到 50） |
| 动作低通 | head 0.5 / legs 0.7 —— 必须与训练一致 |
| 电压自适应 | scale × (7.4/EMA)，钳位 6.0–9.5V，默认关 |
| 总线容错 | COAST_TICKS=3 滑行 60ms；连续错 10 次报障 |

## 电源

NP-F550/F970 2S，带载 8.2V 满 → 6.6V 空；**无电量计无 ADC**，电压=舵机回报；
EMA（~10s）跌破 6.6V → 自动坐下关机。复刻无需设计任何电池监测电路。

## 三个必踩坑

1. `systemctl mask serial-getty@ttyS2`（Armbian 默认 UART2 跑登录台）
2. i2c3 选 M0（pin3/5）必须禁 fusb302 → 失 PD 协商（5V 充电不受影响）
3. NPU 默认关，跑 rknn 前 `setup-npu.sh` + 重启

## 为什么必须是 Linux SoC 而非 MCU

ONNX 50Hz 推理 + 720p30 H.264 硬编 WebRTC + NPU 检测（2Hz，热限 95°C）+ 蓝牙/WiFi +
签名 OTA——STM32/ESP32 做不了。原型阶段用过 Pi Zero 2W（50Hz 即当时选定）。
