# 15 · 拟人化动作（Pixar 台灯式）是怎么搞定的

> 一句话：**不是 RL 探索出来的——是动画师"手工艺"做出来的**。
> Pixar Luxo Jr. 的灵魂 = 迪士尼动画 12 原则（1930 年代定下的手工艺规则）+ 物理。
> 我们的平台已内置完整承载管线：**Animate 面板手摆关键帧 → clip.json → imitate 训练**。
> 动画师负责"情感与节奏"，RL 只负责"让塑料身体真的做到"。

## Pixar 灯为什么动人——动画 12 原则的核心几条

| 原则 | 在鸭子上的体现 |
|---|---|
| **Squash & Stretch（挤压拉伸）** | 落地时身体压扁、跳起时拉长 —— MuJoCo 软接触自动产生一部分 |
| **Anticipation（预备动作）** | 跳之前先蹲一下、转头看之前先眨眼 —— **关键帧里手动加入** |
| **Follow Through（跟随动作）** | 头停了脖子还在晃 —— 物理仿真自动产生 |
| **Overlapping Action（重叠动作）** | 各关节不是同时动，错开 2-3 帧 —— 关键帧时间轴错开 |
| **Slow In / Slow Out（缓入缓出）** | 动作起止要慢，中间快 —— clip 插值器自带 easing |
| **Arcs（弧线）** | 头转动走弧线不走直线 —— 关键帧密集些自然形成 |
| **Secondary Action（次级动作）** | 主动作是点头，次级是身体微晃 —— body_bob 奖励项 |

**RL 自己探索永远发现不了这些**——比如"跳之前先蹲一下"在奖励上是负优化
（多了一个动作=多花能量），只有动画师把它 K 进关键帧，RL 才会执行。

## 在我们系统里的完整流程

```
动画师（你）
  ↓ 在 Animate 面板 / 或写 JSON
关键帧 clip（.json：每关节每时刻的目标角度）
  ↓ imitate 行为训练（DeepMimic 式"跟着做"）
RL 策略 = "跟得上这段编舞的身体控制能力"
  ↓ 部署
真鸭在物理世界里做出这个动作（含真实的惯性/接触/重心转移）
```

**分工原则**：
- 动画师：情感、节奏、预备、跟随（12 原则）
- RL：物理可行性（不让塑料鸭穿模、不摔、关节扭矩不超限）

## 具体例子：四个拟人化动作的 clip 设计

### 1. 好奇张望（curious_peek）
```
关键帧：head_yaw 0 → +0.4（快，0.3s，缓出）→ 停 0.5s → 回 0（慢，0.8s，缓入）
原则：Anticipation（先反向微转 -0.05 再正向转）+ Slow Out
```

### 2. 惊喜跳起（startle_hop）
```
关键帧：蹲（neck -0.1, hip +0.2）0.15s → 爆发跳（hip -0.3）→ 落地缓冲 0.2s
原则：Anticipation（蹲=准备）+ Squash & Stretch（落地自动压扁）
```

### 3. 沮丧低头（dejected）
```
关键帧：neck_pitch 从 0.35 缓慢降到 -0.3（2s），head_pitch 跟随下降，
       body 高度微降（膝盖微曲），保持 3s
原则：Slow In（缓慢陷入）+ Secondary Action（头随身体垂下）
```

### 4. 犹豫迈步（hesitant_step）
```
关键帧：抬起左腿 0.4s → 停在半空 1.5s（wobble 微晃）→ 放下 → 抬右腿 → ...
原则：Slow In / Slow Out + Overlapping Action（身体重心先移，腿再动）
```

## 技术实现：已有的工具完全够用

| 需要什么 | 在哪 | 怎么用 |
|---|---|---|
| 关键帧编辑器 | viewer 🎬 Animate 面板 | 浏览器里拖关节、拖时间轴、自动插值 |
| clip 格式 | `clips/*.json` | `{t, joints[14], rootPitch}` |
| 训练 | `imitate` 行为 + clip | `uv run train-behavior imitate --clip curious_peek` |
| 节律层 | head_cmd 命令槽 | 可叠加：节拍器 + 关键帧编舞可同时跑 |
| 实时表演 | duck-lab viewer | 策略热切换，多个 clip 轮播 |

## 与 RL 探索的关系

| 动作类型 | 用 RL 探索 | 用动画师 K 帧 + imitate |
|---|---|---|
| **平衡/步态**（技术性）| ✓ 正确选择 | ✗ 人类画不出好步态 |
| **卡点舞**（节拍驱动）| ✓ 奖励可量化 | 部分可用 |
| **拟人化情感动作**（艺术性）| ✗ RL 发现不了预备/缓入 | ✓ **唯一正确路径** |
| **杂技**（空翻/后滚）| ✓（官方 backflip 用 RL） | ✓ 都行，RL 更优 |

## 沉淀
官方 lab 的 Animate 面板就是为了这个流程而存在的——**"动画师的 12 原则 + RL 的物理执行力"**
是足式机器人行为设计的正确分工。不是所有动作都该让 RL 自己想。
