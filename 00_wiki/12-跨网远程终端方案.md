# 12 · 跨网远程终端方案（无公网 IP 场景）

> 场景：copizza 服务器与操作者不在同一局域网，且无公网 IP。
> 目标：像局域网一样 SSH/终端控制，跑 Claude Code / Codex / OMP。

## 业界标准答案（2026 主流，社区大量验证）：Tailscale + SSH + tmux

| 组件 | 作用 | 为什么选它 |
|---|---|---|
| **Tailscale** | 组网（WireGuard，点对点直连） | 无公网 IP 也能通；NAT 打洞失败自动走中继；免费 100 台；装完像局域网 |
| **SSH** | 远程终端 | 系统自带，密钥免密 |
| **tmux** | 会话保持 | SSH 断了 Claude Code/Codex 会话不死，重连即回现场 |

手机端加一个 Termius（SSH 客户端）就能在手机上指挥所有机器。

## 备选方案对比

| 方案 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **Tailscale**（推荐） | 免配置、P2P、免费 | 需要登录账号 | 长期多机管理 |
| ToDesk / UURemote | 中文界面、已有账号 | 桌面为主，终端模式弱、速度一般 | 临时看屏幕 |
| Cloudflare Tunnel | 免费隧道 | 需域名，配置重 | 暴露 web 服务 |
| frp 自建 | 完全自控 | 需要一台公网 VPS | 有 VPS 的团队 |
| Claude Code `--remote-control` | 官方原生 | 需要 claude.ai 订阅登录 | 已订阅用户 |

## 本项目落地方案

```bash
# 两台机器各装一次（各 1 分钟）：
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up          # 浏览器登录同一账号

# 之后无论在哪：
ssh copizza@<tailscale-ip 或 magic-name>   # 100.x.x.x
tmux new -s duck                            # 会话保活
claude / codex / omp                        # AI 工具随便跑
```
