## 一、卡点舞（dance）——已实现，正在训练 ✅

**你的洞察是对的**：卡点不需要"听懂"音乐——DJ 放什么歌，节拍就定了。
训练时随机 BPM/风格/相位 = 无穷多首歌，策略学的是"读节拍信号跟身体"，
不是背一段固定舞。

### 接线方式（零框架改动）
```
DanceEnv (behaviors/dance_env.py)  ← 子类化，step() 里每步覆写 head_cmd
  ├─ neck_pitch 命令槽 = A·sin(2πft+φ)     摇摆（行为配方有 head-err 高斯在等）
  ├─ head_pitch 命令槽 = -B·pulse(beat)    节点压头打点
  ├─ head_yaw   命令槽 = C·sign(sin)       4/4 甩头（3拍风格不加）
  ├─ head_roll  命令槽 = 强拍侧倾强调
  └─ _sample_commands 禁用 —— 随机采样不许覆盖节拍
奖励配方 (behaviors/dance.py)：swing 紧/宽双层 + beat_hit + strong_beat ×2 + body_bob
```

### 音乐的"听"分两层
| 层 | 仿真内 | 真机 |
|---|---|---|
| 卡点执行 | DJ 直接写 head_cmd（训练=随机BPM/风格） | 同一策略，通用 |
| 节拍检测 | 不需要（DJ 就是真值） | librosa/madmom onset-beat → 写同一 head_cmd 槽 |

**泛化路径**：策略见过 90-140BPM × 3拍/4拍/摇滚 × 随机相位后，
新歌只是"没见过的相位序列"，槽里给什么跟什么。

**训练多样性**（`DANCE=1 DANCE_BPM=xx`）：首轮 120BPM 固定（dance-v1 在跑）；
下一轮做 BPM curriculum——每 episode 从 [90,140] 均匀采 + 偶尔切 style。

### 音乐文件（抖音神曲/古典/变速曲）
**下载用于训练完全不需要**——仿真里"歌"就是 BPM 数字。真机阶段要放歌时，
用 YouTube/网易云 → librosa 离线提节拍 → JSON 时间轴 → 运行时播放器同步写槽。
变速曲（rubato）用 onset 重估每 0.5s 更新一次 BPM 即可。

## 二、模仿姿势（imitate / 猫猫歪头）——机制已验证，素材 Pipeline 已打通

**结论：不难，反而是这仓库最成熟的能力**——`imitate` 行为 + JSON 关键帧 clip
（DeepMimic 式）：难点从"发明动作"变成"跟着做"，物理（平衡/接触）仍由 RL 解决。

### 已验证
- `clips/cat-tilt.json` 手写"猫猫歪头"关键帧（head_yaw 0→+0.55→0→-0.55→0，2.4s 循环）
- `clip.at(step)` 50Hz 插值正确（歪头 0.55rad 在 t=0.6s 精确到位）
- `BehaviorEnv("imitate", clip_name="cat-tilt")` 全链路可跑

### 人/猫对鸭比划 → clip 的三种来源
1. **Animate 面板手摆**（内置）：浏览器里拖关节摆关键帧 → 存 JSON → "Train this"
2. **视频转关键帧**（Seedance/实拍都行）：
   视频 → 姿态估计（MediaPipe/ViTPose 抽人的骨架）→ 关节重定向映射表
   （人 head_yaw→鸭 head_yaw，人耸肩→鸭 neck_pitch…14 个关节的映射是固定表）
   → 关键帧 JSON → imitate 训练
3. **摄像头实时版**（真机阶段）：MediaPipe 实时骨架 → head_cmd/body_cmd 槽实时写
   —— 这是"实时对镜比划"，同样走命令槽，不用重训

### 为什么"猫猫歪头它就歪头"可行
鸭头有 4 自由度（pitch/yaw/roll/neck），猫歪头=head_roll+head_yaw 组合，
一个 2.4s 循环 clip 就能表达。识别"对面是猫在歪头"是视觉问题（RK3566 NPU
跑 MediaPipe/轻量检测，官方架构里 NPU 检测 2Hz 已预留），识别结果触发
对应 clip 罢了——**行为库 = clip 库，认出什么就播什么**。

## 三、发呆/做梦/玩手手/伸懒腰/单腿舞 —— 同一模板的批量复制

每个都是"一个 clip 或一个配方"：

| 能力 | 实现载体 | 素材 |
|---|---|---|
| 发呆 (idle) | 命令槽全零 + 微随机 head 目标 | 无需训练（zero-command 已训）|
| 做梦 (dream) | 站立下眼睑式 head_pitch 慢波动 + 偶尔抽动 | clip: 8s 循环 |
| 玩手手 (wing) | 翅膀=无手，用 head_roll+neck 互蹭；clip 3s | 手摆或视频 |
| 伸懒腰 (stretch) | 前后腿对角伸展 clip | Animate 面板 5 分钟摆完 |
| 单腿跳舞 | one_leg 配方 + dance 节拍槽 组合微调 | 已有两个组件，融合训练 |

**选型建议**：全做不如做组合——上层"导演"（行为树/LLM）挑 clip+策略热切换，
下层每招一个 ONNX。官方 runtime 本来就支持策略热切换（61 维契约就是为了这个）。
